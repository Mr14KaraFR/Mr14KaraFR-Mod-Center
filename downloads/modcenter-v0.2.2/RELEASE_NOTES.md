# Mr14KaraFR Mod Center 0.2.2

Application Windows portable pour installer et mettre à jour les mods publics Mr14KaraFR.

## Correction

Logo du mod Flammes HQ corrigé : la flamme remplit toute la sortie de l’échappement. Pack Logos v2 inclus.

## Installation

Télécharger **Mr14KaraFR_Mod_Center_0.2.2_Windows.zip**, extraire tout le ZIP, puis ouvrir **Mr14KaraFR-Mod-Center.exe**. Garder le dossier **_internal** à côté de l’EXE.

Le catalogue officiel est déjà connecté. Choisir le dossier **mods** du dossier utilisateur BeamNG et fermer le jeu avant d’installer ou de mettre à jour un mod.

## Mods disponibles

- ECU Studio : **0.16.20**
- Suspension pneumatique : **0.16.1**
- Fumée diesel volumétrique : **0.9.20**
- Flammes & détonations HQ : **6.69.0-HQ**

Les anciennes archives sont sauvegardées à côté du dossier mods, dans **Mr14KaraFR-backups**. Les mods décompressés dans unpacked ne sont pas gérés.

Cette version ajoute les sections Mods et Applications, ECU Studio pour Windows et les mises à jour automatiques des deux applications au lancement. La version 0.1.2 nécessite ce dernier téléchargement manuel pour passer au nouveau système. Les applications ne sont pas signées numériquement.
